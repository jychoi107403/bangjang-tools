# 반응형 웹 디자인(Responsive Web Design) 명세 및 검증 가이드

> **프로젝트**: 방장 용용이 (무료 실무 도구 모음)  
> **적용 버전**: v1.0.0 (전체 도구 RWD 개편)  
> **대상 기기**: 데스크톱(1201px~), 태블릿(769px~1200px), 모바일 스마트폰(320px~768px)  
> **작성 일자**: 2026-09-13  

---

## 1. 개요 및 설계 목표
기존 PC 데스크톱 3단 레이아웃(좌측 네비게이션 사이드바 + 중앙 작업 캔버스 + 우측 설정 패널) 구조를 모바일 스마트폰 및 태블릿 환경에서도 가로 스크롤(Horizontal Overflow) 없이 터치 친화적이고 깔끔하게 작동하도록 **완전한 반응형 웹 디자인(RWD)**으로 전면 개편하였습니다.

### 🎯 핵심 목표
1. **무결점 레이아웃**: 320px 최저 해상도부터 4K 모니터까지 끊김 없는 유동적 그리드 및 플렉스박스 적용
2. **모바일 네비게이션 드로어(Off-Canvas)**: 모바일/태블릿 뷰포트에서 상단 햄버거 메뉴 버튼을 통해 부드럽게 열리고 닫히는 사이드바 구현
3. **도구별 맞춤 세로 스택(Stacked Workflow)**: 메인 작업 캔버스 아래로 설정 사이드바가 자연스럽게 배치되어 한 손 조작 및 스크롤 작업성 극대화
4. **터치 친화적 UI (Touch-First UX)**: 버튼 및 조작 요소의 최소 터치 영역(44px 이상) 보장

## 2. 반응형 브레이크포인트 (Breakpoints)

| 단계 | 브레이크포인트 | 레이아웃 특성 | 사이드바 상태 |
| :--- | :--- | :--- | :--- |
| **Desktop (Large)** | `> 1200px` | 3단 레이아웃 (`260px` + `1fr` + `300px`) | 고정 노출 (좌측 네비 + 우측 설정) |
| **Laptop / Small Desktop** | `1025px ~ 1200px` | 3단 압축 레이아웃 (`220px` + `1fr` + `260px`) | 고정 노출 (패딩 및 폰트 유동 조절) |
| **Tablet (Portrait & Landscape)** | `769px ~ 1024px` | 1단 수직 스택 (`main-content` 100% + 하단 설정) | 숨김 (`.mobile-menu-toggle` 햄버거 토글) |
| **Mobile (Smartphone)** | `~ 768px` | 1단 수직 스택 + 전체 폭 액션 버튼 | 숨김 (오프캔버스 슬라이드 드로어) |
| **Small Mobile** | `~ 480px` | 압축 그리드 (1열 배치, 폰트 축소, 패딩 12px) | 숨김 (전체 화면 드로어) |

## 3. 공통 네비게이션 및 인터랙션 아키텍처

### 3.1 상단 네비바 & 햄버거 메뉴 버튼 (`.mobile-menu-toggle`)
- 데스크톱(`> 1024px`): `display: none`
- 태블릿/모바일(`<= 1024px`): 우측 상단에 40x40px 햄버거 아이콘 버튼 노출
- 활성화(열림) 상태 시 `data-lucide="x"`로 동적 아이콘 전환 및 애니메이션 제공

### 3.2 오프캔버스 사이드바 드로어 (`.sidebar.mobile-open`)
- `position: fixed; top: 0; left: -320px; width: 300px; height: 100vh; z-index: 1000;`
- 열림 시 `left: 0;`으로 부드러운 CSS `cubic-bezier(0.4, 0, 0.2, 1)` 트랜지션 적용
- 배경에 반투명 딤드 오버레이(`.sidebar-backdrop`) 자동 생성 (z-index: 999)
- 사이드바 상단에 직관적인 닫기(X) 버튼(`.sidebar-mobile-close`) 자동 배치

### 3.3 닫기 인터랙션 시나리오
1. 상단 햄버거 버튼 재클릭 시 닫힘
2. 사이드바 우측 상단 닫기(X) 버튼 클릭 시 닫힘
3. 딤드 배경(Backdrop) 영역 터치/클릭 시 닫힘
4. 키보드 `ESC` 키 입력 시 닫힘
5. 메뉴 링크(`<a>`) 클릭 시 페이지 이동과 동시에 닫힘
6. 화면 창 크기를 데스크톱 크기로 리사이즈 시 드로어 자동 리셋

## 4. 도구별 모바일 반응형 상세 명세

### 4.1 메인 홈 (`index.html`)
- **히어로 섹션**: 모바일에서 타이틀 및 설명 폰트 크기 자동 축소, 검색창 폭 100% 유동적 확대
- **카테고리 탭**: 모바일에서 가로 스크롤 터치 스와이프 지원 (`overflow-x: auto`)
- **도구 카드 그리드**:
  - 데스크톱: 4열 (`repeat(auto-fill, minmax(260px, 1fr))`)
  - 태블릿: 2열
  - 스마트폰(480px 이하): 1열 전체 폭 카드

### 4.2 QR 코드 생성 (`qr-code.html`)
- **미리보기 영역**: 모바일 화면 폭에 맞춰 캔버스 크기 자동 리사이징 (`max-width: 100%`)
- **설정 패널**: 텍스트 입력창, 컬러 칩, 로고 업로드 영역이 세로로 정돈
- **저장 버튼**: 모바일에서 전체 폭(`width: 100%`)으로 손쉬운 터치 다운로드 지원

### 4.3 배경 제거·바꾸기 (`remove-bg.html`)
- **캔버스 비교 뷰**: 모바일에서 좌우 2단 비교 대신 상하 2단 비교 또는 단일 토글형 뷰로 유동적 전환
- **투명 체커보드**: 화면 폭에 맞춘 가로 스크롤 방지 뷰어 박스
- **배경 교체 칩**: 모바일 탭으로 빠른 단색/그라데이션/이미지 선택

### 4.4 사진 모자이크 (`mosaic.html`)
- **캔버스 작업대**: 터치 및 핀치 줌을 고려한 뷰포트 맞춤 캔버스 래퍼
- **브러시/강도 슬라이더**: 모바일에서 엄지손가락으로 쉽게 조절 가능한 대형 트랙 & 썸

### 4.5 파일명 일괄 변경 (`batch-rename.html`)
- **파일 목록 테이블**:
  - 모바일에서 수평 스크롤 박스 지원 (`overflow-x: auto; -webkit-overflow-scrolling: touch;`)
  - 긴 파일명에 대한 텍스트 말줄임(`text-overflow: ellipsis`) 처리
- **규칙 설정 카드**: 모바일에서 접기/펼치기 및 1열 폼 정렬

### 4.6 영상/블로그 도구들 (`video-trim-gif`, `video-to-gif`, `screen-record-gif`, `blog-formatter`, `pdf-to-word`)
- 미구현 준비 안내 카드(Coming Soon) 모바일 센터링 및 유동적 패딩
- 비디오 플레이어 및 타임라인 컨트롤 100% 모바일 너비 적응
