# 상단 GNB 드롭다운 네비게이션 및 풀와이드 레이아웃 기능 명세서

## 1. 개요
기존의 고정 좌측 사이드바(240px)를 상단 네비게이션 바(GNB)로 완전히 이동 통합하여, 실무 도구 화면의 좌우 작업 영역을 100% 꽉 찬 **풀와이드 스튜디오(Full-width Studio)** 형태로 전환하고, 상단 탭에 마우스를 올리거나 클릭했을 때 세부 도구 목록이 말풍선 레이어로 **"보였다 안보였다(드롭다운 토글)"** 하도록 구축한 기능 명세입니다.

## 3. 인터랙션 및 동작 원리

1. **마우스 호버 (Hover) 노출**:
   - 상단 `[이미지 도구]`, `[영상 도구]`, `[블로그 도구]` 버튼에 마우스 커서를 올리면 `0.15초` 부드러운 페이드인과 함께 말풍선 레이어가 즉시 나타납니다.
2. **클릭 및 터치 (Click / Touch) 고정 토글**:
   - 버튼 클릭 시 드롭다운이 열려 있는 상태로 고정되며, 다시 클릭하면 닫힙니다.
3. **외부 클릭 감지 (Click Outside)**:
   - 상단 메뉴 외에 화면의 다른 곳(캔버스, 설정창 등)을 클릭하면 열려 있던 드롭다운이 자동으로 닫힙니다.
4. **키보드 접근성 (ESC Key)**:
   - 키보드의 `ESC` 키를 누르면 즉시 드롭다운이 닫힙니다.
5. **말풍선 디자인 (Balloon Pointer)**:
   - 드롭다운 레이어 상단 중앙에 세련된 삼각형 꼭지점(`gnb-dropdown-arrow-up`)이 배치되어 현재 선택된 상위 탭을 명확하게 가리킵니다.

## 4. 레이아웃 변화 (풀와이드 스튜디오)

- **기존 구조**: 좌측 고정 사이드바(240px) + 중앙 캔버스 + 우측 설정창(320px)
- **개편 후 구조**: 상단 슬림 네비바(60px 고정) + **중앙 풀와이드 캔버스(가로 폭 100% 확장)** + 우측 설정창(320px)
- **장점**: 
  - 사진 편집, 배경 제거, 모자이크 작업 시 캔버스 작업 공간이 240px 이상 넓어져 작업 몰입도와 시안성이 극대화되었습니다.
  - 모바일 및 태블릿에서는 햄버거 메뉴를 통해 슬라이드 드로어로 모든 도구에 간편하게 접근할 수 있습니다.
