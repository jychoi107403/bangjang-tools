```

| 1. 왼쪽 사이드바    | 2. 중앙 메인 작업 영역                      | 3. 우측 배경 편집 사이드바    |
```

## 2. 세부 테스트 항목 및 검증 결과 (Checklist)

### (1) 이미지 추가 및 로드 (Input & Drop Zone)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :---: |
| 1.1 | **클립보드 붙여넣기 (`Ctrl+V`)** | `Win+Shift+S`로 화면 캡처 후 `Ctrl+V` 입력 시 즉시 사진 로드 및 1차 자동 누끼 실행 | ✅ 정상 |
| 1.2 | **[붙여넣기] 버튼 클릭** | 브라우저 클립보드 API를 통해 복사된 이미지를 자동 감지하여 캔버스에 추가 | ✅ 정상 |
| 1.3 | **[파일 추가] 버튼** | 이미지 파일(`JPG`, `PNG`, `WebP` 등) 선택 시 캔버스에 즉시 로드 | ✅ 정상 |
| 1.4 | **드래그 앤 드롭** | 탐색기에서 이미지를 드래그하여 점선 영역에 놓으면 자동 등록 및 작업대 전환 | ✅ 정상 |
| 1.5 | **용량 및 해상도 최적화** | 25MB 이하 파일 수용, 2,048px 초과 고해상도 이미지는 비율을 유지하며 고속 연산 크기로 자동 스케일링 | ✅ 정상 |
| 1.6 | **상태 배너 실시간 갱신** | 사진 로드 시 `1 / 1장 · W × Hpx`로 실시간 동기화 | ✅ 정상 |
| 1.7 | **[전체 삭제] 초기화** | 상단 `[전체 삭제]` 클릭 시 컨펌 후 작업대와 히스토리를 깔끔하게 초기화 | ✅ 정상 |

### (2) 스마트 자동 배경 제거 엔진 (Auto Remove Engine)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :---: |
| 2.1 | **외곽 연결 배경 Flood Fill** | 사방 가장자리(상/하/좌/우)에서부터 연결된 배경과 외곽 카드 박스 영역을 BFS 알고리즘으로 자동 탐색하여 투명화 | ✅ 정상 |
| 2.2 | **색상 유사도 분리** | 모서리 8방향 배경 샘플 색상과의 가중 유클리드 거리를 계산하여 피사체 본체만 정밀 추출 | ✅ 정상 |
| 2.3 | **제거 범위 (민감도) 조절** | `제거 범위 (5 ~ 80)` 슬라이더 변경 시 수치 배지 갱신 및 실시간 외곽선 재계산 | ✅ 정상 |
| 2.4 | **경계 부드러움 (Feathering)** | `경계 부드러움 (0 ~ 8px)` 조절 시 계단 현상(Aliasing)을 방지하고 알파 채널 그라데이션으로 매끄럽게 처리 | ✅ 정상 |
| 2.5 | **로딩 인디케이터** | 배경 제거 연산 중 "배경을 분석하고 누끼를 따는 중..." 스피너 오버레이 표시 | ✅ 정상 |

## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **독립 ES 모듈 격리 원칙 (`assets/js/tool-remove-bg.js`)**:
   - `remove-bg.html`은 `<script type="module" src="assets/js/tool-remove-bg.js"></script>` 형태로 로드되므로 전역 스코프 오염이 없습니다.
   - 공통 유틸리티 함수가 필요할 때는 `import { downloadBlob, canvasToBlob, readFileAsDataURL, loadImage } from './utils.js';`를 활용합니다.
2. **CSS 네임스페이스 격리 (`assets/css/tool-remove-bg.css`)**:
   - 모든 전용 스타일은 `.tool-remove-bg` 하위 클래스로 한정되어 있으므로 다른 도구 페이지 스타일에 영향을 주지 않습니다.
3. **Canvas 읽기 성능 최적화**:
   - 픽셀 연산이 빈번한 Canvas 컨텍스트 생성 시 `{ willReadFrequently: true }` 옵션을 유지하여 브라우저 가속 메모리 경고를 방지합니다.
4. **브러시 커서 좌표 보정**:
   - 캔버스 크기와 실제 브라우저 렌더링 너비가 다를 경우 `scaleX`, `scaleY` 비율 계산을 적용하여 마우스 좌표 오차가 발생하지 않도록 유지합니다.
