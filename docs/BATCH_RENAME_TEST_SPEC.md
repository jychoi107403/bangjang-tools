## 2. 세부 테스트 항목 및 검증 결과 (Checklist)

### (1) 다중 파일 등록 및 추가 (Input & Drop Zone)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :---: |
| 1.1 | **클립보드 붙여넣기 (`Ctrl+V`)** | `Win+Shift+S`로 화면 캡처 후 `Ctrl+V` 입력 시 `캡처_YYYYMMDD_번호.png`로 자동 명명 및 목록 누적 추가 | ✅ 정상 |
| 1.2 | **[붙여넣기] 버튼 클릭** | 브라우저 클립보드 API를 통해 복사된 이미지를 자동 감지하여 목록에 추가 | ✅ 정상 |
| 1.3 | **[파일 추가] 다중 파일 선택** | 탐색기에서 모든 포맷(이미지, 문서, 영상 등 복수 선택) 일괄 목록 등록 | ✅ 정상 |
| 1.4 | **드래그 앤 드롭 일괄 등록** | 폴더/탐색기에서 파일들을 드래그하여 점선 영역에 놓으면 일괄 등록 및 즉시 테이블 렌더링 | ✅ 정상 |
| 1.5 | **용량 및 개수 제한** | 최대 2,000개 파일 수용 및 배지에 `N개 · 합계 용량(KB/MB)` 실시간 갱신 | ✅ 정상 |
| 1.6 | **[전체 삭제] 초기화** | 상단 `[전체 삭제]` 클릭 시 컨펌 후 목록 및 카운터 일괄 초기화 | ✅ 정상 |

### (2) 실시간 리네이밍 규칙 연산 (Live Renaming Pipeline)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :---: |
| 2.1 | **공통 이름 실시간 반영** | `공통 이름` 인풋에 텍스트(예: `루나유`, `상품이미지`) 입력 시 테이블의 "변경 후 이름" 컬럼이 즉시 업데이트 | ✅ 정상 |
| 2.2 | **시작 번호 가변 설정** | `시작 번호 (기본 1)` 변경 시 지정한 번호부터 순차적으로 증가하여 파일명에 매핑 | ✅ 정상 |
| 2.3 | **번호 자릿수 패딩 (Padding)** | 자릿수 `1`(`1, 2, 3`), `2`(`01, 02, 03`), `3`(`001, 002, 003`), `4`(`0001...`) 등 즉시 패딩 적용 | ✅ 정상 |
| 2.4 | **원본 확장자 100% 보존** | 원본 파일의 확장자(`.png`, `.jpg`, `.pdf`, `.mp4` 등)가 새 이름 뒤에 손실 없이 완벽하게 유지 | ✅ 정상 |

---

### (3) 테이블 행 조작 & 정렬 (Table Interaction)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :--- | :---: |
| 3.1 | **순서 위로 이동 (`[ ↑ ]`)** | 특정 행의 `[ ↑ ]` 클릭 시 이전 행과 자리가 바뀌고 순번 번호가 즉시 자동 재부여됨 | ✅ 정상 |
| 3.2 | **순서 아래로 이동 (`[ ↓ ]`)** | 특정 행의 `[ ↓ ]` 클릭 시 다음 행과 자리가 바뀌고 순번 번호가 즉시 자동 재부여됨 | ✅ 정상 |
| 3.3 | **개별 `[ 삭제 ]`** | 해당 행만 목록에서 제거되고 나머지 파일들의 순번이 자동으로 1씩 당겨짐 | ✅ 정상 |
| 3.4 | **[원본 이름순 정렬] 버튼** | 클릭 시 원본 파일명을 기준으로 가나다/ABC/숫자 자연어 정렬(Natural Sort) 수행 | ✅ 정상 |

---

### (4) ZIP 일괄 압축 다운로드 & 보안 (Export & Security)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :--- | :---: |
| 4.1 | **[새 이름으로 ZIP 저장] 버튼** | 등록된 파일이 없을 때는 비활성화(`disabled`), 파일이 1개 이상일 때 보라색 활성화 | ✅ 정상 |
| 4.2 | **JSZip 로컬 일괄 압축** | 각 파일의 바이너리 내용을 그대로 유지하면서 변경된 새 파일명으로 압축된 ZIP 생성 | ✅ 정상 |
| 4.3 | **압축 진행 상태 표시** | 대용량 파일 압축 시 `ZIP 압축 중 (N / Total)...` 진행률 표시 | ✅ 정상 |
| 4.4 | **네이밍 규칙** | `[공통이름]_일괄변경_[타임스탬프].zip` 형태로 다운로드 | ✅ 정상 |
| 4.5 | **100% 로컬 보안 보장** | 파일 바이너리를 외부 서버로 전송하지 않고 브라우저 내에서만 100% 안전하게 패키징 | ✅ 정상 |

## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **독립 ES 모듈 격리 (`assets/js/tool-batch-rename.js`)**:
   - `batch-rename.html`은 `<script type="module" src="assets/js/tool-batch-rename.js"></script>` 형태로 로드됩니다.
2. **CSS 전용 네임스페이스 (`assets/css/tool-batch-rename.css`)**:
   - `.tool-batch-rename` 및 `.tool-batch-rename-page` 스코프를 사용하여 타 도구와 스타일 간섭이 발생하지 않습니다.
3. **ArrayBuffer 직접 스트리밍**:
   - `item.file.arrayBuffer()`를 사용하여 텍스트/이미지/바이너리 파일 모두 내용 손상 없이 원본 그대로 보존하여 새 이름으로 ZIP에 패킹합니다.
