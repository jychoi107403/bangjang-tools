## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **독립 ES 모듈 격리 원칙 (`assets/js/tool-batch-rename.js`)**:
   - `batch-rename.html`은 `<script type="module" src="assets/js/tool-batch-rename.js"></script>` 형태로 로드되므로 전역 스코프 오염이 없습니다.
2. **타임스탬프 캡처 파일명 규칙**:
   - `캡처_${year}${month}${date}${hours}${mins}${secs}${ms}_1.png` 포맷으로 클립보드 캡처 시 고유한 파일명이 자동 생성됩니다.
3. **JSZip 라이브러리 연동**:
   - `window.JSZip`을 통해 브라우저 로컬에서 고속으로 ZIP 아카이브를 빌드하여 다운로드합니다.
4. **HTML 특수문자 방어 (XSS 방지)**:
   - `escapeHtml` 함수를 통해 사용자가 업로드한 파일명에 `<script>`나 특수문자가 포함되어 있어도 안전하게 텍스트로 이스케이프 렌더링됩니다.
