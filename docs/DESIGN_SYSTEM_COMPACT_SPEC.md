# 방장 도구 모음 - 콤팩트 디자인 시스템 및 시각적 계층 구조 명세

> **문서 버전**: v2.0.0 (시각적 계층 구조 개편 & 1줄 콤팩트 툴바 표준)  
> **적용 범위**: 전체 도구 12개 페이지 및 메인 대시보드 허브  
> **작성 일자**: 2026-09-13  

---

## 1. 개편 배경 및 핵심 UX 철학

### 1.1 기존 문제점
- 상단 헤더 영역(브레드크럼 + 영문 서브타이틀 + 큰 제목 + 긴 설명 + 보안 알림 박스)이 세로로 약 200px 이상을 차지하여, 정작 핵심 기능인 **작업대 캔버스와 컨트롤 패널이 스크롤 아래로 밀리는 현상** 발생.
- 화면에 너무 많은 텍스트와 박스가 분산되어 사용자의 시선 집중도 저하.

### 1.2 새로운 디자인 원칙: "Focus-First Studio"
1. **1줄 콤팩트 툴바(Compact Toolbar)**: 높이 52px의 1줄 툴바로 상단 정보(도구명, 보안 배지, 도움말 버튼)를 통합하여 스크롤 없이 **작업 공간을 첫 화면(Above the Fold)에 100% 확보**.
2. **정보와 기능의 역할 분리**:
   - 상시 작업: 캔버스 작업대와 우측 조작 패널에만 시선 집중.
   - 튜토리얼 및 도움말: 우측 상단 `[💡 도움말]` 버튼 클릭 시 나타나는 **모달 팝오버**로 분리하여 필요할 때만 확인.
3. **대시보드형 메인 허브**:
   - `index.html`을 단순 단일 도구가 아닌, 자주 쓰는 TOP 4 추천 도구 + 실시간 검색창 + 카테고리별 그리드를 갖춘 직관적인 대시보드로 개편.

## 2. 콤팩트 툴바 표준 규격 (`.tool-compact-header`)

```html
<header class="tool-compact-header">
    <div class="tool-compact-left">
        <a href="index.html" class="tool-back-link" title="모든 도구 목록으로"><i data-lucide="chevron-left"></i></a>
        <div class="tool-compact-badge-icon"><i data-lucide="[도구아이콘]"></i></div>
        <div class="tool-compact-title-wrap">
            <h1 class="tool-compact-title">[도구명]</h1>
            <span class="tool-security-tag"><i data-lucide="shield-check"></i> [보안/특징 배지]</span>
        </div>
    </div>
    <div class="tool-compact-right">
        <button class="btn-help-trigger" id="btn-help-trigger" title="사용 방법 및 안내">
            <i data-lucide="help-circle"></i>
            <span>도움말</span>
        </button>
    </div>
</header>
```

---

## 3. 공통 도움말 모달 시스템 (`.help-modal-backdrop`)

- **트리거**: 툴바의 `.btn-help-trigger` 클릭
- **제어**: `assets/js/global-nav.js`가 자동으로 열림/닫힘/ESC/백드롭 클릭 연동
- **구성**:
  - `1단계 / 2단계 / 3단계` 직관적인 단계별 튜토리얼
  - 100% 프라이버시 보호 및 로컬 처리 안심 콜아웃
  - 하단 확인 및 닫기 버튼

## 4. 메인 대시보드 (`index.html`) 구성 체계

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 콤팩트 히어로 배너 (제목 + 무설치 배지 + 실시간 도구 검색창)        │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 🔥 자주 쓰는 추천 도구 TOP 4 (배경 제거, QR코드, 파일명 변경, 모자이크) │
├────────────────────────────────────────────────────────────────────────┤
│ 3. 📂 이미지 실무 도구 6종 그리드                                      │
├────────────────────────────────────────────────────────────────────────┤
│ 4. 🎬 영상 & 블로그 실무 도구 5종 그리드                               │
└────────────────────────────────────────────────────────────────────────┘
```
