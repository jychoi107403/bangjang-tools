## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **독립 ES 모듈 격리 원칙 (`assets/js/tool-qr-code.js`)**:
   - `qr-code.html`은 `<script type="module" src="assets/js/tool-qr-code.js"></script>` 형태로 로드되므로 전역 스코프 오염이 없습니다.
2. **`qr-code-styling` 라이브러리 연동**:
   - `window.QRCodeStyling`을 통해 SVG와 Canvas를 모두 지원하며, `exportQr.download()`로 클라이언트 사이드에서 즉시 다운로드됩니다.
3. **고해상도 렌더링 파이프라인**:
   - 미리보기 화면은 가벼운 280px 캔버스로 렌더링되고, 다운로드 시 사용자가 선택한 `512px / 1,024px / 2,048px` 크기에 맞춰 별도 인스턴스로 선명하게 생성 및 저장됩니다.
