## 2. 세부 테스트 항목 및 검증 결과 (Checklist)

### (1) 이미지 다중 추가 및 등록 (Input & Multi-Gallery)

| :---: | :--- | :--- | :---: |
| 1.1 | **클립보드 붙여넣기 (`Ctrl+V`)** | `Win+Shift+S`로 화면 캡처 후 `Ctrl+V` 입력 시 즉시 갤러리 카드로 등록 (누적 추가 지원) | ✅ 정상 |
| 1.2 | **[붙여넣기] 버튼 클릭** | 브라우저 클립보드 API를 통해 복사된 이미지를 자동 감지하여 목록에 추가 | ✅ 정상 |
| 1.3 | **[파일 추가] 다중 파일 선택** | 탐색기에서 복수 파일(`multiple`) 선택 시 일괄 갤러리 등록 | ✅ 정상 |
| 1.4 | **드래그 앤 드롭 일괄 등록** | 여러 장의 사진을 드래그하여 점선 영역에 놓으면 일괄 등록 및 뷰어 렌더링 | ✅ 정상 |
| 1.5 | **용량 및 개수 제한** | 25MB 초과 파일 차단 알림, 최대 30장 초과 방지 | ✅ 정상 |
| 1.6 | **상태 배너 동기화** | `N / 30장 · 선택 K번 · W × Hpx`로 실시간 상태 표시 | ✅ 정상 |
| 1.7 | **개별 `[삭제]` 및 `[전체 삭제]`** | 카드 내 `[삭제]` 클릭 시 해당 사진만 제거, 상단 `[전체 삭제]` 시 일괄 초기화 | ✅ 정상 |
| 1.8 | **사진별 독립 상태 보존** | 사진을 전환해도 각 사진마다 설정한 모자이크 영역, 강도, 히스토리가 100% 개별 유지됨 | ✅ 정상 |

| 2.1 | **빈 곳 드래그 (새 영역 생성)** | 캔버스 빈 곳을 클릭 드래그하면 즉시 새로운 모자이크 사각/원형 영역 생성 | ✅ 정상 |
| 2.2 | **영역 내부 드래그 (위치 이동)** | 선택된 모자이크 영역 내부를 마우스로 잡고 드래그하면 자유롭게 이동 (`move` 커서) | ✅ 정상 |

## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **독립 ES 모듈 격리 (`assets/js/tool-mosaic.js`)**:
   - `mosaic.html`은 `<script type="module" src="assets/js/tool-mosaic.js"></script>`로 로드되어 전역 스코프 오염이 없습니다.
   - ZIP 라이브러리는 `window.JSZip`을 안전하게 참조합니다.
2. **CSS 네임스페이스 격리 (`assets/css/tool-mosaic.css`)**:
   - 모든 스타일은 `.tool-mosaic` 하위 선택자로 한정되어 다른 도구 페이지 스타일에 영향을 주지 않습니다.
3. **순수 캔버스 내보내기**:
   - 저장 시 화면에 보이는 조절 점선과 8개 핸들은 제외하고, 순수 이미지 + 모자이크 + 워터마크만 별도 Canvas에 렌더링하여 다운로드합니다.
