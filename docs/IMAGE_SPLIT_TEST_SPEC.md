## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **독립 ES 모듈 격리 원칙 (`assets/js/tool-image-split.js`)**:
   - `image-split.html`은 `<script type="module" src="assets/js/tool-image-split.js"></script>` 형태로 로드되므로 다른 도구 스크립트와 충돌하지 않습니다.
   - ZIP 라이브러리는 `window.JSZip` 전역 객체를 안전하게 참조하여 사용합니다.
2. **CSS 네임스페이스 격리 (`assets/css/tool-image-split.css`)**:
   - 모든 스타일은 `.tool-image-split` 하위 선택자로 격리되어 있어 전역 스타일에 영향을 주지 않습니다.
3. **분할 좌표 정밀 계산**:
   - `generateAndRenderPieces` 함수에서 `(x1 / targetWidth) * naturalWidth` 공식을 사용하여 리사이징된 캔버스와 원본 이미지의 비율 오차 없이 정밀하게 크롭합니다.
4. **개별 파일 네이밍 룰**:
   - 조각별 파일명은 `[cleanName]_part01.png`, `_part02.png`와 같이 2자리 0패딩(`padStart(2, '0')`)을 적용하여 파일 정렬 시 순서가 꼬이지 않도록 유지합니다.
