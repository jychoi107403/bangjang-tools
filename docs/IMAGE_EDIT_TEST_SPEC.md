## 1. 주요 기능 아키텍처 요약

```
+---------------------------------------------------------------------------------------------------+
| 0. 글로벌 네비게이션 헤더 (방장 용용이 브랜드 고정)                                                 |
+---------------------+---------------------------------------------+-------------------------------+
| 1. 왼쪽 사이드바    | 2. 중앙 메인 작업 영역                      | 3. 우측 이미지 설정 사이드바  |
| - 11개 실무 도구    | - 상단 툴바 (붙여넣기, 파일추가, 전체삭제)  | - 세로 크기 맞춤 (800px)      |
|   (독립 HTML 분리)  | - 상단 카드 갤러리 (썸네일, 해상도, 편집)   | - 전체 밝기 (%)               |
| - 보안 안내 배너    | - 하단 대형 뷰어 (선택 사진 실시간 합성)    | - 테두리 (두께, 색상)         |
|                     | - 하단 [이미지 저장] 대형 버튼              | - 워터마크 (9방향, 농도, 여백)|
|                     | - 더블클릭/[편집] -> [사진 정밀 편집 모달]  | - 저장 형식 (JPG, PNG, WebP)  |
+---------------------+---------------------------------------------+-------------------------------+
```

## 2. 세부 테스트 항목 및 검증 결과 (Checklist)

### (1) 이미지 추가 및 등록 (Input & Drop Zone)

| 번호 | 테스트 항목 | 세부 동작 및 기대 결과 | 상태 |
| :---: | :--- | :--- | :---: |
| 1.1 | **클립보드 붙여넣기 (`Ctrl+V`)** | `Win+Shift+S`로 화면 캡처 후 `Ctrl+V` 입력 시 즉시 갤러리 카드로 등록됨 | ✅ 정상 |
| 1.2 | **[붙여넣기] 버튼 클릭** | 브라우저 클립보드 API를 통해 복사된 이미지를 자동 감지하여 추가 | ✅ 정상 |
| 1.3 | **[파일 추가] 버튼** | 다중 이미지 파일(`JPG`, `PNG`, `WebP`, `GIF` 등) 선택 시 일괄 등록 | ✅ 정상 |
| 1.4 | **드래그 앤 드롭** | 탐색기에서 이미지를 드래그하여 점선 영역에 놓으면 자동 등록 | ✅ 정상 |
| 1.5 | **용량 및 개수 제한** | 25MB 초과 파일 차단 알림, 최대 30장 초과 시 안내 메시지 출력 | ✅ 정상 |
| 1.6 | **카운트 뱃지 동기화** | 등록된 사진 수에 맞춰 `N / 30장 · 한 장 25MB 이하` 실시간 갱신 | ✅ 정상 |
| 1.7 | **빈 상태(Empty State) 전환** | 사진이 0장일 때 안내 문구 노출, 1장 이상 등록 시 갤러리 그리드 노출 | ✅ 정상 |

### (2) 상단 사진 카드 갤러리 인터랙션 (Gallery Cards)

## 3. 향후 유지보수 가이드 (코드 수정 시 참고)

1. **ES 모듈 격리 유지**:
   - `assets/js/tool-image-edit.js`는 `type="module"`로 로드되므로 전역 변수 충돌이 없습니다.
   - 유틸리티 함수가 필요할 때는 `import { downloadBlob, canvasToBlob } from './utils.js'` 형태로 불러와 사용합니다.
2. **CSS 네임스페이스 규칙**:
   - 모든 스타일은 `.tool-image-edit` 또는 `.modal-overlay` 내부 스코프에서만 동작하도록 유지하여 타 페이지와의 스타일 간섭을 방지합니다.
3. **EXIF 메타데이터 보안 유지**:
   - 다운로드 시 반드시 순수 Canvas API를 거쳐 생성된 Blob을 `downloadBlob`에 전달하여 개인정보 노출을 방지합니다.
