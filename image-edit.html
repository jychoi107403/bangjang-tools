이미지 편집

캡처 일괄 편집 · 로컬 무손실
Win+Shift+S로 캡처 → Ctrl+V로 붙여넣기 사진을 계속 추가하고, 더블클릭해 정밀 편집하세요.
0 / 30장 · 한 장 25MB 이하

이미지를 여기에 드래그하거나 Ctrl + V로 붙여넣으세요.

상단의 [붙여넣기] 또는 [파일 추가]도 사용할 수 있습니다.

사진을 더블클릭하거나 카드 내 [편집]을 누르면 정밀 편집창이 열립니다.

이렇게 사용하세요

  1. Win+Shift+S로 캡처한 뒤 이 화면에서 Ctrl+V로 붙여넣으세요. 파일 선택·끌어놓기도 가능합니다.
  2. 사진을 클릭하면 아래쪽에 대형 화면으로 나타나며, 더블클릭 또는 [편집]을 누르면 정밀 편집창이 열립니다.
  3. 오른쪽 설정에서 [세로 크기 맞춤], [밝기], [워터마크]를 지정하면 아래쪽 화면에 실시간 반영되며, [이미지 저장]을 누르면 일괄 저장됩니다.

저장 시 개인정보 및 촬영 위치가 포함된 EXIF 메타데이터를 100% 자동 제거하여 안전하게 보호합니다.

크기 변경 없음 · 사진별 편집 크기 유지
체크하면 모든 사진의 세로를 맞추고, 가로는 각 사진의 비율에 맞춰 자동 조절합니다. 해제하면 개별 편집 크기로 저장합니다. 자르기·회전·크기 변경은 사진을 더블클릭하세요.

이미지 편집기 사용 가이드
1
캡처 후 바로 붙여넣기 (Ctrl+V)

Win+Shift+S로 화면을 캡처한 후 웹 브라우저에서 Ctrl+V를 누르면 즉시 편집 보드에 추가됩니다.

2
더블클릭 정밀 편집 & 주석 그리기

사진 카드를 더블클릭하면 팝업 편집기가 열려 자르기(Crop), 회전, 텍스트 삽입, 화살표/도형 그리기, 모자이크를 적용할 수 있습니다.

3
세로 결합 & 일괄 압축 다운로드

우측 설정에서 개별 파일 저장 또는 세로로 하나로 이어붙이기를 선택하여 한 번에 다운로드하세요.

안전한 로컬 렌더링
모든 캔버스 연산은 브라우저 하드웨어 가속을 이용해 로컬에서 즉시 실행되며 개인 파일이 서버로 유출되지 않습니다.
