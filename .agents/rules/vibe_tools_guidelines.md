# Vibe Tools 프로젝트 개발 가이드라인 및 규칙

이 문서는 지금까지 개발된 `Vibe Tools` 프로젝트의 핵심 구조와 개발 원칙을 요약한 **공식 가이드라인**입니다.
이후의 모든 에이전트 작업은 **반드시 이 기준을 엄격하게 준수**해야 합니다.

## 1. 최우선 핵심 원칙 (Core Principle)

> [!CAUTION]
> **"사용자가 명시적으로 지시하지 않은 부분은 절대 임의로 변경하지 않는다."**

- **의도치 않은 사이드 이펙트 방지**: 특정 기능을 수정할 때, 기존에 잘 작동하던 다른 기능이나 UI 레이아웃이 틀어지지 않도록 격리하여 작업합니다.
- **사전 동의**: 대규모 구조 변경이 필요하거나 기존 로직을 수정해야 할 경우, 반드시 사용자에게 먼저 물어보고 승인을 얻은 후 진행합니다.
- **안전한 파일 수정**: 불필요하게 파일 전체를 덮어쓰거나 포맷팅을 훼손하지 않고, 정확히 필요한 부분만 수정(Patch)합니다.

## 2. 프로젝트 아키텍처 및 기술 스택

- **순수 웹 기술 (Vanilla Tech)**: React/Vue 등의 프레임워크 없이 순수 HTML, CSS, JavaScript(ES6 Modules)만으로 구동됩니다.
- **모듈화**:
  - 각 도구는 독립된 HTML 파일(`image-compress.html`, `batch-rename.html` 등)과 전용 독립 JS/CSS 모듈을 가집니다.
  - 공통 로직은 `assets/js/utils.js` (DOM에 종속되지 않은 순수 헬퍼 함수)에 모아서 사용합니다.
- **인코딩 규칙**: 모든 소스코드 파일은 반드시 **`UTF-8 (BOM 없음)`** 포맷으로 저장하여 한글 깨짐을 방지합니다.

## 3. 다국어 지원 (i18n) 시스템 규칙

모든 페이지와 도구는 한국어(KO)와 영어(EN) 전환을 완벽히 지원해야 합니다.

- **중앙 관리**: 모든 번역 텍스트는 `assets/js/i18n.js` 파일 내의 `translations` 객체(ko, en)에서 중앙 집중식으로 관리합니다.
- **HTML 정적 텍스트 바인딩**:
  - 태그 내부 텍스트: `data-i18n="번역키"`
  - Placeholder: `data-i18n-placeholder="번역키"`
  - 툴팁(Title): `data-i18n-title="번역키"`
- **JavaScript 동적 텍스트 바인딩**:
  - JS 코드 내의 alert 메세지나 동적 렌더링 텍스트는 반드시 `window.i18n.t('번역키', '기본문구')` 형태로 감싸서 작성합니다.
- **안전한 i18n 수정**: `i18n.js` 파일은 구조가 민감하므로 텍스트 수정 시 문법 오류가 나지 않도록 매우 주의해야 합니다.

## 4. UI/UX 및 스타일링 (디자인 시스템)

- **Vibe 테마 (보라색 계열)**: 기본 브랜드 컬러로 보라색(`--primary-color: #8b5cf6`, `#7c3aed` 등)을 사용합니다.
- **아이콘**: 모든 아이콘은 `Lucide` 라이브러리(`<i data-lucide="..."></i>`)를 사용합니다.
- **사용자 경험 (UX)**:
  - 캡처 후 붙여넣기(Ctrl+V)와 드래그앤드롭(Drag & Drop)을 기본으로 지원해야 합니다.
  - 처리 시간이 걸리는 작업(ZIP 저장 등) 시에는 버튼에 스피너(로딩 아이콘)를 표시하여 멈춘 것처럼 보이지 않게 합니다.

## 5. 주요 구현 도구 현황

1. **이미지 용량 줄이기 (`image-compress.html`)**
   - 캔버스 기반의 리사이즈 및 포맷 변환(WebP, JPEG). PNG 양자화 스마트 압축 적용.
2. **이미지 뷰어 및 편집기 (`image-edit.html`)**
   - Fabric.js(또는 Canvas API)를 활용한 자르기, 모자이크, 텍스트 추가, 그리기 기능. 
3. **파일명 일괄 변경 (`batch-rename.html`)**
   - 여러 파일의 이름을 규칙(공통 이름 + 번호)에 따라 일괄 변경.
   - JSZip을 사용한 일괄 다운로드 기능.
   - **(최신 통합)** 이미지 압축 기능이 결합되어, 이름 변경과 동시에 WebP 등 용량 줄이기를 수행할 수 있음.
